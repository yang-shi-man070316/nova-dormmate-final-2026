# DormMate 宿舍温湿度监测项目
## 项目介绍
本项目为网页端宿舍温湿度监测系统。
- M1：基础温湿度输入、环境分析、历史记录展示
- M2：增加CSV导出功能，Python脚本读取CSV，自动生成趋势折线图、柱状图，生成report.html报告
- M3：新增本机交互模块：摄像头快照、TTS语音播报、ASR语音识别指令。支持手动与语音控制摄像头，不连续采集画面。

## 功能使用
1. 温湿度分析：输入温度、湿度，点击【分析环境】，查看环境状态与建议，自动保存到历史记录。
2. 导出CSV：一键导出记录为csv文件，用于Python数据分析。
3. 摄像头模块
   - 打开摄像头：开启预览
   - 拍照保存快照：截取当前画面下载图片
   - 关闭摄像头：释放摄像头硬件资源，停止采集
4. 语音交互
   - 朗读当前状态：手动按钮，语音播报环境状态
   - 开始语音识别，支持指令：
     - 当前状态 / 朗读状态：播报环境状态
     - 拍照：触发摄像头拍照
     - 关闭摄像头：关闭摄像头

## 运行环境
- 浏览器：Edge浏览器（推荐，Web语音识别兼容性最好）
- Python：matplotlib（用于绘图生成报告）
